# BlockRunner
BlockRunner is a casual game developed with Godot Engine 3.5. for the <a href="https://itch.io/jam/lame-jam-26">Lame Jam</a> 2023<br> The objective of the game is to drag the blocks to prevent the player from falling, offering an endless and immersive gaming experience.

<img src="https://img.itch.zone/aW1nLzExNTYyMDYxLnBuZw==/original/CHUmIx.png" width="300">

## Admob support
The project uses the **[Godot-Android-Admob-Plugin](https://github.com/Shin-NiL/Godot-Android-Admob-Plugin)** library for integrating AdMob ads on Android.  
If you want to use this project as a reference for correctly implementing AdMob in Godot Engine, make sure to follow the official instructions provided in the library repository.


## Play now
- **Playable on Web and Mobile**: Supports play directly from the browser, both on PC and smartphone.
- **Available for Android**: You can download the APK from Itch.io and install it on your device.
